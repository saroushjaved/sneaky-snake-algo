# Sneaky Snake Algorithm

Final year project: **Hands on Algorithm Acceleration using Heterogeneous Computing Systems**.

This repository is being organized to archive the project's Sneaky Snake genome pre-alignment filtering implementations and supporting documentation.

## Current contents

- `Hetergenous_Thesis_FYP_Thesis.pdf`: project thesis.
- Source code and build instructions will be added as the project archive is organized.

## Planned scope

- CPU implementation using C++ and OpenMP
- FPGA implementation and supporting build files
- Data preparation and benchmarking scripts
- Selected results and reproducible examples

Sneaky Snake is an existing algorithm; this repository documents the final year project's implementations and experiments.
